# System Design & Data — Learning Repo

Notes, exercises and diagrams for learning system design and data engineering. One folder per topic; each has a `README.md` (notes) and optional `exercises.md`.

## Roadmap

1. `01-fundamentals/` — client/server, latency vs throughput, scalability, CAP, consistency
2. `02-networking/` — DNS, HTTP, load balancers, CDN, REST vs gRPC
3. `03-storage/` — SQL vs NoSQL, indexing, replication, sharding, caching
4. `04-messaging/` — queues, pub/sub, Kafka, event-driven design
5. `05-data/` — ETL/ELT, batch vs stream, warehouses, data modeling
6. `06-case-studies/` — URL shortener, chat app, news feed, rate limiter

## How to use

- Read the topic notes, then do the exercises.
- Add questions to the topic's `exercises.md`; answer in your own words.
- Commit your answers; review them together.
